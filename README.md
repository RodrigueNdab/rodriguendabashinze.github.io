## General information

This repository has code for my academic website.

The website is built using the Hugo Academic CV Theme, deployed and hosted on GitHub Pages / Netlify.

To locally deploy, call: `hugo server`

## Hugo Academic CV Theme

This website uses the [**Hugo Academic CV Theme**](https://github.com/HugoBlox/theme-academic-cv)
